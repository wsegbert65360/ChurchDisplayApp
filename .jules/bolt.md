## 2024-05-14 - WPF Image Decoding Performance
**Learning:** While `File.ReadAllBytesAsync` prevents disk I/O from blocking the UI thread, `BitmapImage.EndInit()` still synchronously decodes the image data. If executed on the UI thread, this decoding process can cause noticeable UI stuttering or freezes, especially with large, high-resolution images common in media projection apps.
**Action:** When loading images dynamically in WPF, perform the `BitmapImage` initialization (including `EndInit()`) inside a background thread (e.g., using `Task.Run`). Crucially, call `.Freeze()` on the resulting `BitmapImage` before returning it. Freezing the object makes it read-only, which allows it to be safely accessed and bound across different threads, such as passing it back to the UI thread for display.
